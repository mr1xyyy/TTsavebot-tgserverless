# TikTok yuklovchi bot (Telegram Serverless)

1. @BotFather → botingiz → Serverless → yoqing; CLI Access token oling.
2. Loyiha papkasida `npm install`, keyin `npm run cloud:login` buyrug'ini bajaring.
3. Bu papkadagi `tgcloud/`, `public/`, `tgcloud.jsonc` fayllarini loyihaga qo'ying.
4. `npx tgcloud push` → chiqqan `https://app<id>.tgcloud.ai/` manzilini `tgcloud/lib/config.js` dagi APP_URL ga yozing.
5. `npx tgcloud push && npx tgcloud migrate`
6. BotFather → Mini App / Menu Button URL sifatida o'sha manzilni qo'ying.
